# YESGAP Demo Login Credentials

For local development only. These are the default credentials produced by the development seed configuration. Never use or publish these credentials in production.

Passwords are stored as hashes in MongoDB and cannot be read back from the database. The seed sets these passwords only when it creates an account; it does not reset a password that was changed later. If you changed values in `server/.env`, the configured counts, email, username, or passwords may differ from this list.
